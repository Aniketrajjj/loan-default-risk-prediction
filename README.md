# Loan Default Risk Analysis & Prediction

A data-science project exploring loan applicant information and using machine-learning classification to study loan default risk.

## Repository contents

- **`ldrp-v2.ipynb`** — project notebook containing the analysis and code.
- **`credit_risk_dataset.csv`** — dataset used by the notebook.
- **`Aniket_Raj_12416201_Project_Report.docx`** — project report.
- **`requirements.txt`** — Python dependencies.
- **`.gitignore`** — files and folders that should not be committed.

## Project workflow

The notebook is the primary source for the exact methods and results used in this project. A workflow for this kind of project may include:

1. Load and inspect the dataset.
2. Explore variables and data quality.
3. Prepare data for analysis and modelling.
4. Train and evaluate classification models, if implemented in the notebook.
5. Summarize findings and limitations.

**Refer to the notebook for the exact methods, model names, and evaluation results.** This README does not claim particular scores without verifying the notebook outputs.

## Getting started

### Requirements

- Python 3
- Jupyter Notebook
- Packages listed in `requirements.txt`

### Run locally

1. Download or clone this repository.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Launch Jupyter:

   ```bash
   jupyter notebook
   ```

4. Open `ldrp-v2.ipynb` and run the cells in order. Keep `credit_risk_dataset.csv` in the same folder unless the notebook specifies another path.

## Important note

This is an academic/data-science project. A predictive model should not be used as the sole basis for real lending decisions; credit decisions require validation, fairness assessment, explainability, and appropriate human oversight.
